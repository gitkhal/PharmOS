# PharmOS

**Community pharmacy, simplified.**

PharmOS is a desktop-first pharmacy management system designed for small community pharmacies.

The project prioritizes a small number of reliable, well-executed workflows rather than a large set of partially implemented features.

## Core Features

- **Inventory and Expiry Control**
  - Track medicines, quantities, batches, and expiry dates
  - Low-stock thresholds and alerts
  - Barcode-based medicine lookup
  - Near-expiry warnings

- **Sales / POS**
  - Barcode scan or product search
  - Automatic total calculation
  - Transaction recording
  - Receipt printing
  - Automatic inventory deduction

- **Customer and Prescription Records**
  - Lightweight customer profiles
  - Searchable prescription history
  - Purchase history

- **Smart Stock Assistant**
  - Uses sales history and current inventory
  - Suggests likely shortages
  - Suggests reorder quantities
  - All recommendations require staff confirmation

- **Dashboard and Reports**
  - Low-stock alerts
  - Near-expiry items
  - Sales activity
  - Inventory totals
  - Basic historical reports

## Product Principles

- Reliable before clever
- Few clicks for common tasks
- Attention, not clutter
- Human-controlled automation
- Hardware-friendly desktop design

## Target Users

PharmOS is designed for pharmacists and pharmacy staff working in a single small community pharmacy.

The system is intended for frequent desktop use with:

- Keyboard and mouse
- Barcode scanner
- Receipt printer
